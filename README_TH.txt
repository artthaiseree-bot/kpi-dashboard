KPI DASHBOARD 2026 — คู่มือเริ่มต้น (ภาษาไทย)

1) แตกไฟล์ dashboard-fixed.zip ไปไว้ในโฟลเดอร์ที่ต้องการ
2) เข้าโฟลเดอร์ dashboard
3) ดับเบิลคลิก start.bat
4) รอจนหน้าต่างแสดงข้อความ "KPI Dashboard พร้อมใช้งาน"
5) เปิดหน้าเว็บ http://localhost:3000 (ระบบจะเปิดให้อัตโนมัติ)

การอัปเดตข้อมูล Excel
- ให้นำไฟล์ Excel ฉบับอัปเดตมาแทนที่ไฟล์ data/20261119_KPI_2026.xlsx
- ควรใช้ชื่อไฟล์เดิม หรือแก้ excelPath ใน config.json ให้ตรงกับชื่อใหม่
- เมื่อบันทึกไฟล์ ระบบจะอ่านข้อมูลใหม่อัตโนมัติ หรือกดปุ่ม Refresh Data
- อย่าปิดหน้าต่าง Command Prompt หากต้องการให้ Dashboard ทำงาน

หมายเหตุ
- ต้องติดตั้ง Node.js รุ่น LTS ในเครื่องก่อนใช้งานครั้งแรก
- หากโฟลเดอร์ไม่มี node_modules ตัว start.bat จะติดตั้งแพ็กเกจให้อัตโนมัติ (ต้องเชื่อมต่ออินเทอร์เน็ต)
- ไฟล์ Excel ต้นฉบับถูกเก็บไว้ในโฟลเดอร์ data
- ห้ามลบหรือย้ายไฟล์ Excel ออกจากโฟลเดอร์ data เว้นแต่จะแก้ config.json ให้ชี้ไปยังไฟล์ใหม่

การปรับปรุงในฉบับนี้
- อ่านข้อมูลจาก 22 ชีตรายละเอียด โดยใช้ตำแหน่งหัวตารางจริง
- ใช้ prefix ชื่อชีตเป็นตัวกำหนด SHOP / OP / COMMON / TEMP
- รองรับชีต TEMP ที่มีคอลัมน์ว่างเพิ่มทางซ้าย
- แก้การแปลงพื้นที่แบบ comma-decimal เช่น 75,80 ให้เป็น 75.80
- แยก Approved / Partial / รอดำเนินการ / Cancelled
- ทำให้ตาราง Matrix และรายผู้ตรวจใช้ตัวกรองชุดเดียวกับ KPI
- ปรับการนับเดือนจากค่าวันที่ Excel จริง แทนการ split ข้อความ
- รวมยูนิตซ้ำทั้งหมดไว้ในกลุ่มเดียว และรายงานข้อผิดพลาดของข้อมูลที่อ่านไม่ได้
